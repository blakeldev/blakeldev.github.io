实战指南

狂暴战士循环

狂暴战士的核心在于维持 暴怒 的层数并利用 致死打击 和 旋风斩 保持怒气。

核心循环： 1. 使用暴怒获取怒气。
2. 优先使用致死打击（增加怒气）。
3. 怒气充足时使用旋风斩。
4. 保持撕裂Debuff。

爆发期开启 死亡之愿，配合 致死命令（武器天赋）或 怒火中烧（狂暴天赋）进行爆发输出。

武器战士爆发

武器战士依赖 致死打击 和 压制 的配合。压制是武器战士最高的单体爆发技能。

连招建议： 1. 保持撕裂Debuff。
2. 使用致死打击降低护甲。
3. 保留怒气等待压制冷却。
4. 爆发期：压制 -> 致死打击 -> 旋风斩。

在BOSS战前摇阶段，确保身上有致死Debuff，并在爆发窗口期集中释放伤害。

防御战士T位技巧

防御战士的仇恨主要来源于 盾牌猛击 和 致死打击。

仇恨管理： 1. 开怪前使用 嘲讽。
2. 每次格挡后立即使用 盾牌猛击。
3. 保持 盾牌格挡 持续时间。
4. 使用 盾击 打断法术。

当受到伤害时，怒气恢复天赋能帮助你更快地产生仇恨技能。

属性分析

狂暴战士

  • 急速： 最优先属性，缩短暴怒和致死打击的冷却。
  • 暴击： 提高怒火中烧和致死命令的触发几率。
  • 精通： 提高暴怒的怒气获取效率。
  • 力量： 增加攻击强度，次优先级。

武器战士

  • 暴击： 武器战士非常依赖暴击来维持怒气循环。
  • 急速： 缩短致死打击和压制冷却。
  • 力量： 提高基础攻击力。
  • 精通： 提高致死打击的额外伤害。

防御战士

  • 格挡值： 直接减少受到的伤害。
  • 躲闪： 提高闪避几率。
  • 护甲穿透： 对高护甲BOSS效果显著。
  • 力量： 增加攻击强度，提高仇恨。
常见问题 (FAQ)
WOW5.0 狂暴战士应该优先点哪个天赋？
狂暴战士最核心的是“怒火中烧”和“死亡之愿”，前者提供爆发怒气，后者提供爆发强度。其次是“暴怒”和“致死打击”，这是怒气的来源和主要输出手段。
防御战士如何保证仇恨不掉？
防御战士必须依靠“盾牌猛击”作为仇恨的主要来源。每次格挡后立即使用盾牌猛击，并保持“盾牌格挡”技能开启，确保持续的高仇恨输出。
武器战士的爆发技能是什么？
武器战士的爆发技能是“压制”。这是一个强制近战攻击的技能，通常配合致死打击使用，能造成极高的单体伤害。
